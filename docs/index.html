어떤 주제의 아이디어를 도출할까요?

주제를 입력하면 서로 겹치지 않고 빠짐없이 구성된 하위 아이디어를 만들어 드립니다. 각 아이디어는 원하는 만큼 계속 더 깊게 확장할 수 있습니다.

시작하려면 우측 상단 설정에서 Gemini API 키를 먼저 등록해 주세요.

0개 항목 · 0개 핵심 영역 · 자동 저장됨

    보고서가 완성되었습니다

    ✉ 메일 작성

    첨부 안내 메일 작성 버튼은 기본 메일 프로그램(Outlook 등)을 열어 제목과 본문만 자동으로 채웁니다. 브라우저 보안 정책상 파일은 자동 첨부되지 않으므로, 내려받은 워드 파일을 메일 창에 직접 첨부한 뒤 직접 발송해 주세요.

    이 앱은 서버 없이 브라우저에서만 동작합니다. 입력한 API 키와 작성 내용은 이 기기 밖으로 나가지 않습니다.

    설정

    키는 이 브라우저 안에만 저장되며, 구글 외의 어떤 서버로도 전송되지 않습니다.

    무료 사용 가능한 모델 목록입니다. 속도가 중요하면 Lite 모델을 선택하세요.

    쉼표·세미콜론·줄바꿈으로 구분해 여러 명을 넣을 수 있습니다. 메일 작성 시 모두 수신자로 들어가며, 자동 발송은 하지 않습니다.
